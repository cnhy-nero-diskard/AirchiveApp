## Design
Map slider positions to the exact ordered supported-option list. Slider changes are local drafts; releasing the slider submits one command if changed. Use a prominent, stable thumb, a continuous track, aligned stop ticks, and the supported value labels. Show the selected value and the device's current confirmed value while they differ. Slider crossings and enabled temperature/power actions give light native interaction haptics; remote command outcomes use only their separate status feedback. Unknown and single-option states remain explicit. Reflow identity and power controls vertically below 440 dp or above 1.2 text scale, retaining switch semantics and authority gates.
